# Instructions for AI agents writing rule packs

When asked to create or change a rule or rule pack in this folder, follow the workflow in
[`.claude/skills/rule-pack-author/SKILL.md`](../.claude/skills/rule-pack-author/SKILL.md). It applies to
any agent (Claude Code, GitHub Copilot, others).

The rule format is defined in [`docs/rule-packs.md`](../docs/rule-packs.md), and the node and edge
types in [`docs/knowledge-graph.md`](../docs/knowledge-graph.md) §3–4. Never invent a node, edge, or clue
type: propose it to the person instead.
